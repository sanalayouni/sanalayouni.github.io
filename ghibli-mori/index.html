Ghibli Mori

What it is

Ghibli Mori (“Ghibli forest”) brings the films together in one place, grouped by mood: fantasy epics, slice of life, war and history, cozy family stories. Each film has its own page with a trailer and a threaded comment section.

Behind the interface is a REST API with JWT sign-in, role-based admin tools and rate-limited, validated requests, organised in clean layers so each part is easy to test and change.

Features

  • Curated film libraryMood categories, a featured film and a Top Rated rail.
  • Film pagesTrailers and threaded comments for every film.
  • Accounts and profilesRegister and sign in with JWT; bcrypt-hashed passwords; editable bio, picture and favourites.
  • Admin panelAdmins create, view and remove users, protected by role checks.
  • Soundtrack libraryAlbum art, track lists and a built-in player.
  • Guess the movieA quick quiz with casual and harder modes.
  • Interface detailsScroll-reveal animations and a custom animated cursor.
